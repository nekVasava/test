CalcNest Privacy and Data

This notice describes the current CalcNest 1.0.0-rc.2 web app.

Calculations and local data

Calculator inputs are processed in your browser. This release contains no calculation API or server endpoint, and the app code does not send calculation inputs to a backend.

Calculation history, custom currency rates, and the local Pro Demo setting are stored in this browser's local storage. If persistent storage is unavailable, CalcNest uses temporary in-memory storage and displays a Session Only warning; that fallback data is lost when the app session ends. You can remove saved history in the app or clear this site's browser data.

Sharing and exports

The Share action creates a URL containing the selected calculator and its input values, then copies it to your clipboard. Anyone who receives or opens that URL can see those values. Avoid putting sensitive information in a share link.

CSV export creates a file containing your history and downloads it to your device. The file is not uploaded by the app.

Hosting and network requests

The app's static files are hosted by GitHub Pages. Loading or updating the app makes ordinary HTTPS requests to that host; GitHub may process connection information such as IP address, browser details, and requested files under the GitHub Privacy Statement. The app includes no analytics integration or remote calculation service in this release.

The service worker caches the app's static files on your device for offline use.

Support

For questions or bug reports, use CalcNest GitHub Issues. No support email is published for this project.
